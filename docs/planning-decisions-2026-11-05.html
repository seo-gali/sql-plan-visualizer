기획서를 고치며 대신 고른 것

결과가 달라지는 선택만 모았어요. 프로그램 기능을 새로 만든 작업은 아니에요.

먼저 볼 범위와 기준

원래 계획의 미완료 항목 유지

다른 DB의 실제 측정, SQL 고쳐 쓰기, 인덱스 추천 등은 아직 없어요. 계획에서 지우지 않고 빈 체크로 남겼어요. 앞으로 만들 범위를 볼 때 확인할 부분이에요.

작업 계약의 위치 유지

새 기획서.md는 지금 상태를 담은 설명서로 정했어요. 작업의 기준 파일인 .project/plan.md와 기존 규칙은 바꾸지 않았어요.

따로 묻지 않고 고른 작성 방법

문서에 맞춘 도표 코드

기획서의 20개 절과 Mermaid 4개는 유지했어요. HTML은 상자와 화살표를 HTML/CSS로 그렸어요. 별도 그림 파일·도구는 없어요.

코드에 맞춘 이름·버전

지금 쓰는 --vendor와 Python 3.13.15로 적었어요. 예전 이름을 쓰게 하려고 프로그램을 바꾸지는 않았어요.

없는 기능도 보이는 기록

문장 종류 전용 칸과 원본 계획 전체 보관도 아직 없다고 적었어요. 일부 값만 보관하는 것을 전체 보관이라 부르지 않았어요.

옛 시험과 이번 확인 분리

258개 통과는 이전 실행 기록이에요. 이번에는 링크·명령을 살피고, DB에 붙지 않는 HTML·JSON 예제만 실행했어요.

설치된 환경의 예제 검사

설치 오류가 남아 있어 --no-sync를 썼어요. 자료 보관함에는 연결하지 않았고 SQL 원문도 그대로 남겼어요.

새 문서의 찾는 길 추가

요청하신 이름으로 프로젝트 맨 위에 저장하고 README에 길을 달았어요. 부품 목록·Lock·DB·Git은 바꾸지 않았어요.
