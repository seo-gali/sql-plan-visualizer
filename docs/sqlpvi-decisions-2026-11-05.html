1비어 있던 ‘완료 기준’을 제가 채움

지난 시험 기록으로 기준과 완료 표시를 채웠어요. 시험 통과와 Git 저장을 나눴어요. 이 완료 기준의 확인이 필요해요.

2설명 그림은 보는 앱에 따라 다름

Mermaid라는 그림 글자를 골랐어요. 지원하는 앱이 필요해요. 문서 그림 10개의 실제 모양은 아직 확인하지 못했어요.

따로 묻지 않고 고른 방법과 범위

새 결과 폴더 자동 생성

분석이 끝나면 폴더를 만들어요. 실패한 분석은 새 폴더를 만들지 않아요.

표의 특별 지시 4종 허용

계획만 보는 읽기 지시를 골랐어요. 잠금을 강제하거나 모르는 지시는 계속 막아요.

추천을 두 가지로 확대

줄 세우기와 자료 짝짓기가 임시 파일을 썼을 때 점검해요. 실제 숫자가 있어야 해요.

DB 연결 부품 선택

부품 추가는 승인받았어요. 따로 큰 연결 도구가 필요 없는 pymssql 2.4.6을 골랐어요.

기다리는 시간 제한

조회는 5초, 잠금 대기는 1초로 정했어요. 오래 걸리는 명령은 끝까지 기다리지 않아요.

접속 번호 변경·옛 DB 보관

막힌 51433 대신 14330을 골랐어요. 옛 시험 DB는 지우지 않아 공간을 계속 써요.

내 PC의 가짜 자료로 시험

공개 시험 암호만 썼어요. 준비 명령은 시험 계정에 권한을 다시 줘요.

직접 재는 DB는 한 종류

DB 세 종류의 계획을 봐요. 실제로 돌려 재는 기능과 추천은 PostgreSQL만 제공해요.

모르는 숫자는 빈칸 유지

빠진 값은 짐작하지 않아요. 서로 다른 DB의 숫자가 같은 뜻이라고 묶지 않아요.

새 접속 주소 먼저 선택

PostgreSQL의 새 주소 설정을 먼저 써요. 없을 때만 예전 설정을 써요.

연결 부품은 쓸 때 불러오기

MariaDB·SQL Server 부품이 없어도 파일 분석은 돼요. DB에 붙을 때 설치를 안내해요.

이미 설치된 부품으로 검사

설치 오류 뒤에는 기존 부품을 썼어요. 새 설치 오류는 아직 남아 있어요.

문서 범위와 옛 기록 유지

전체 약속·규칙·단계 안내도 고쳤어요. 옛 점수 211개는 오늘 258개와 나눠 남겼어요.

기능을 넓히는 선 유지

질문 비서·개인정보 가리기·먼 DB 연결 통로는 추가하지 않았어요. 추천도 글로만 보여 줘요.

시험과 Git 완료 분리

Git 저장소가 없어 온라인 저장은 남겼어요. 이 기록은 문서 첫 화면과 같은 docs 폴더에 보관해요.
